ÉTAPE 1 - Validez localement (1 minute)
─────────────────────────────────────────
npm run lint      # Vérifier TypeScript
npm run build     # Construire frontend
npm run start     # Lancer serveur

Puis testez: http://localhost:3000/api/health


ÉTAPE 2 - Poussez vers GitHub (1 minute)
──────────────────────────────────────────
git add .
git commit -m "Fix Render deployment"
git push origin main


ÉTAPE 3 - Redéployez sur Render (5-10 minutes)
────────────────────────────────────────────────
Option A - Automatique:
  GitHub Actions détecte le push
  → Pipeline se lance
  → Docker construit
  → Render redéploie

Option B - Manuel:
  1. https://dashboard.render.com
  2. Sélectionnez votre service
  3. Cliquez "Manual Deploy"
  4. Attendez 5-10 minutes

Option C - Force (si toujours en erreur):
  1. Settings → "Clear build cache & redeploy"
  2. Attendez la reconstruction

Troubleshooting:

1. Vérifiez les logs Render:
   Dashboard → Logs → Cherchez les erreurs VITE

2. Vérifiez les variables:
   Settings → Environment → NODE_ENV = production

3. Force rebuild:
   Settings → "Clear build cache & redeploy"

4. Vérifiez GitHub:
   Que les fichiers soient bien updated:
   - vite.config.ts avec allowedHosts
   - server.ts avec servage static
